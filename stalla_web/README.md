# STALLA Web (admin)

Back-office React + TypeScript + Vite. Voir le [README racine](../README.md) pour lancer la stack et [l'architecture](../docs/ARCHITECTURE.md).

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # typecheck + build
```

`VITE_API_BASE_URL` : URL de l'API (voir `src/core/constants.ts`).
